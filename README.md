# Alisa Pavlova — GitHub Pages

Это лёгкая готовая версия сайта. Загрузите **содержимое этой папки** в корень репозитория GitHub.

После загрузки откройте **Settings → Pages**, в поле **Source** выберите **Deploy from a branch**, затем выберите ветку `main` и папку `/(root)`.

Адрес сайта будет выглядеть так:

`https://ВАШ_ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`

Важно: перед реальной публикацией замените демонстрационные реквизиты и согласуйте юридические документы с юристом.
